# Month 6 — Albion Online Screenshots Directory

Place your 20–50 Albion Online screenshots in this directory:
`public/images/month6/`

For example:
- `albion-1.jpg`
- `albion-2.png`
- `first-dungeon.jpg`
- `our-island.png`
- etc.

Then, update your gallery list in `src/museum/galleryData.js` with the filenames, and optionally add categories, captions, or dates.
